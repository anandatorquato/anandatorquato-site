# anandatorquato.com

Landing page da Ananda Torquato: sites, robôs de WhatsApp com IA e tráfego pago ("Máquina de Clientes").

- Site estático: `index.html` + `assets/`
- Hospedagem: Netlify (deploy automático a cada push na `main`)
- **WhatsApp:** o número fica na constante `WHATSAPP` no fim do `index.html`. Enquanto estiver vazia, os botões abrem o direct do Instagram @torquato.ananda.
